Files:
- index.html: complete mobile-friendly website with booking inquiry form, artist roster, event archive and social links.

FREE PUBLISHING:
1. Open https://github.com and create a free account (if needed).
2. Create a new public repository named geekboyz-website.
3. Upload index.html to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. GitHub Pages will provide a free public website address after deployment.

The booking form currently creates a message to copy and send through Instagram/Facebook; it does not collect or store submissions. Add a business email or a form service later if you want submissions delivered automatically.
